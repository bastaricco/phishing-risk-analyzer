# Phishing Risk Analyzer

A beginner-friendly Python program that asks questions about a suspicious
email and reports a **low**, **medium**, or **high** phishing risk.

## Run it

Make sure Python 3 is installed, then run:

```bash
python3 phishing_risk_analyzer.py
```

Answer each question with `yes` or `no`. The score is only a guide: when an
email seems suspicious, do not click links or open attachments. Verify the
message using a trusted way to contact the supposed sender.
